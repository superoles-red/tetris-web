# Тетрис (Tengen, NES) — веб-порт без эмулятора

**Играть:** https://superoles-red.github.io/tetris-web/

Порт запускает **оригинальный Tetris с NES**, который вы приносите сами: один
файл `.nes`. Код игры из вашего ROM статически перекомпилируется в WebAssembly
прямо на вашем устройстве. Эмулятора NES в проекте нет — только наш
перекомпилятор, наш PPU/APU и оригинальные данные вашего картриджа.

- мы не поставляем и не храним игру: ни ROM, ни графику, ни музыку;
- конвертация происходит на вашем устройстве, файл никуда не отправляется;
- графика и звук в игре — ровно те, что в вашем ROM (PPU/APU из него);
- интерфейс оболочки — наш, на русском и английском;
- установка на главный экран, офлайн-запуск, сохранения и рекорды
  (для известных дампов), кнопка «другой ROM» в любой момент.

## Какой файл нужен

Один файл — дамп картриджа Tengen Tetris для NES, `.nes`, около 48 КБ.
Поддерживаются известные дампы (см. `data/dumps.json`) и другие NES-ROM
с небанкованными мапперами (0, 3, 148) в совместимом режиме.

## Что внутри

- `src/nes/compile.js` — наш статический 6502 → WASM перекомпилятор;
- `src/nes/ppu.js`, `src/nes/apu.js` — модели видеопроцессора и звука;
- `src/nes/console.js` — шина, тактирование, прерывания, снапшоты;
- `docs/ARCHITECTURE.md` — устройство движка и контракты модулей.

Лицензия кода — MIT. Сторонние компоненты и происхождение — в
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Игровых данных в репозитории
нет и не должно быть; см. `docs/ARCHITECTURE.md`, §9.

## Разработка

```bash
npm install              # jsnes нужен только для сравнения с эталоном (dev)
npm run serve            # локальная статика на http://localhost:8080
npm test                 # тесты без игровых ROM
```
